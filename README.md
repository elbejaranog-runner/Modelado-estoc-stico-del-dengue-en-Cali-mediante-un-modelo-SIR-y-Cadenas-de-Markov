# Modelado-estoc-stico-del-dengue-en-Cali-mediante-un-modelo-SIR-y-Cadenas-de-Markov
En este trabajo se combinan ambas ideas: por un lado, se construye un modelo SIR discreto visto como Cadena de Markov; por otro, se utiliza MCMC para estimar sus parámetros a partir de los casos semanales de dengue confirmados en Cali durante 2024
